# Peer Ranking Dashboard

Dashboard เทียบอันดับกองทุนของ บลจ. ที่เลือก กับ Peer Group สำหรับรายงาน Performance for IC ทุกสิ้นเดือน

> ⚠️ ข้อมูลทั้งหมดใน repo นี้เป็น **ข้อมูลสมมติ** (กองทุน ผลตอบแทน อันดับ AUM Net Flow สุ่มขึ้นเอง) ห้ามใช้จริง
> มีเพียงชื่อ บลจ. ที่ใช้จริง เพื่อให้ตัวกรองทำงานได้

## ไฟล์
- `index.html` — Dashboard v6 ไฟล์เดียว เปิดใน Chrome ได้เลย จะแสดงข้อมูลสมมติ ก.ย. 2569 (พร้อมประวัติสมมติ ก.ค./ส.ค.)
- `sample-data/` — ไฟล์ Excel สมมติ รูปแบบเดียวกับ Source.xlsx / IC Benchmark.xlsx (ก.ค.–ก.ย. 2569) และ AUM_NetFlow ไว้ลองอัปโหลด

## ใช้กับข้อมูลจริง
1. เปิด `index.html` ด้วย Chrome
2. เปิดส่วน "ข้อมูล & ตั้งค่า" แล้วอัปโหลด `IC Benchmark.xlsx` ก่อน ตามด้วย `Source.xlsx` (หลายเดือนได้)
3. เลือก บลจ. / ช่วงเวลา / กลุ่มกองทุน ดูกราฟ ตาราง และ Export PowerPoint ได้

ไฟล์ถูกอ่านในเบราว์เซอร์เครื่องตัวเองเท่านั้น ไม่ส่งไปที่ไหน
