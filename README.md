# Peer Ranking Dashboard (KTAM)

Dashboard เทียบอันดับกองทุน KTAM กับ Peer Group (Morningstar) สำหรับรายงาน Performance for IC ทุกสิ้นเดือน

## ไฟล์
- `index.html` — Dashboard เวอร์ชัน v6 (ไฟล์เดียว เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร)

## วิธีใช้
1. ดาวน์โหลด `index.html` แล้วเปิดด้วย Chrome
2. เปิดส่วนตั้งค่า แล้วอัปโหลด `IC Benchmark.xlsx` ก่อน ตามด้วย `Source.xlsx` (Morningstar) (อัปหลายเดือนได้)
3. เลือก บลจ. / ช่วงเวลา / กลุ่มกองทุน ดูกราฟ ตาราง และ Export PowerPoint ได้

## หมายเหตุ
- repo นี้ไม่มีข้อมูลจริง (Source.xlsx, IC Benchmark.xlsx) ข้อมูลถูกอ่านในเบราว์เซอร์เครื่องตัวเองเท่านั้น
- แท็บเงินไหล/AUM ใช้ข้อมูลจำลอง ห้ามใช้จริง
